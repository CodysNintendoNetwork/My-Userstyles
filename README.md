# How to use these Userstyles
1. Install Stylus for [Chrome](https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne),[Firefox](https://addons.mozilla.org/firefox/addon/styl-us/), or [Opera](https://addons.opera.com/en/extensions/details/stylus/). 
2. Go [here]([https://sites.google.com/view/codymkw/userstyles#h.p_O-Zcmyjpvt0U](https://userstyles.world/user/codymkw)) and find the style you want click it then press the install button on their page.
3. That's it nothing else needs to be done you can return to those pages to update them or check for updates from within the extension.
